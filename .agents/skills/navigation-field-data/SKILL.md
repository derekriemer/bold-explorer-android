# Navigation field data

Use this skill only for audio-log analysis or recorded-walk scenario tests.
Read the relevant reference before acting:

- For a JSONL log investigation, read [references/audio-log-schema.md](references/audio-log-schema.md).
- To create or assess a replayable field fixture, read [references/recorded-walk-scenarios.md](references/recorded-walk-scenarios.md).

Treat raw logs, GPX files, database copies, coordinates, names, marker text,
and absolute dates as private source data. Do not add them to the repository.
